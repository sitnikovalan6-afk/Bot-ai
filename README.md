# Telegram Clone AI Bot

## Возможности

Главный бот:

/start
/help
/clone

Администраторы:

/create key USER_ID

Например:

/create key 123456789

Где:

123456789 — Telegram ID пользователя,
которому предназначен ключ.

Ключ нельзя использовать другому пользователю.

## Администраторы ключей

@hedgehoblock
@FSBIJ

Только они могут создавать системные ключи.

## Как работает /clone

1. Пользователь пишет:

/clone

2. Бот просит токен Telegram-бота.

3. Бот проверяет токен через Telegram API.

4. Бот сообщает:

"Для продолжения нужен системный ключ.

Где получить ключ:
@hedgehoblock
@FSBIJ"

5. Администратор создаёт ключ:

/create key USER_ID

6. Пользователь отправляет полученный ключ.

7. Бот проверяет, что ключ принадлежит именно этому Telegram ID.

8. Ключ помечается использованным.

9. Подключённый бот начинает работать через общую AI-систему.

## AI

Используется:

groq/compound-mini

Compound Mini поддерживает встроенный Web Search и Visit Website. 

## Установка

Python 3.10+.

Переменные:

BOT_TOKEN
GROQ_API_KEY

Запуск:

python bot.py

## Важно

Файл:

data/clones.json

содержит токены подключённых Telegram-ботов.

Не публикуй его и не передавай посторонним.

Не запускай одновременно две копии программы с одинаковым BOT_TOKEN.
